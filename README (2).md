# 📉 Customer Churn & Retention Analytics

## Project Overview
A complete data analytics project identifying churn drivers, customer-risk segments, and revenue at risk using SQL and Python.

## Business Questions
- What is the overall churn rate?
- Which contracts and plans have the highest churn?
- Does satisfaction influence churn?
- Do support tickets indicate churn risk?
- Which regions have higher churn?
- How much revenue is at risk?
- Which customers should receive retention attention?

## Tech Stack
**SQL • Python • Pandas • Matplotlib • GitHub**

## Dataset
Synthetic portfolio dataset containing **5,000 customer records** with subscription, billing, engagement, support and satisfaction attributes.

## KPIs
Customer Count • Churned Customers • Churn Rate • Average Monthly Charges • Revenue at Risk • Churn by Contract • Churn by Plan • Churn by Satisfaction
